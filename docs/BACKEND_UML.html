System Overview

Docket is an AI-native tax practice management platform built for Antonio Vazquez, a solo enrolled agent in Montclair, CA with ~200 clients. The platform automates everything around the return -- client communication, document collection, pipeline management, billing -- while keeping the human in full control of all AI outputs.
CRITICAL SAFETY RULE: All AI outputs are quarantined until human approval. No AI-generated data ever touches production tables directly. One compliance mistake = license revocation. IRC Section 7216 violations carry criminal penalties.

Return Stage Pipeline (State Machine)

Every client progresses through 7 linear stages. Any stage can branch to extended. Stage transitions are logged to the audit trail and trigger downstream side effects (action items, notifications, insight generation).

Business Rule: Payment MUST be received BEFORE signature can be collected. This is Antonio's legal safeguard -- once Form 8879 is signed and the return is filed, collecting payment becomes significantly harder. The pipeline enforces: payment_received → signature_sent, never the reverse.

Security Architecture

Convex has no database-level Row Level Security (RLS). All security is enforced at the application layer with a 3-layer defense model. Every query and mutation must pass all three layers.

IRC Section 7216: Criminal penalties for unauthorized disclosure of tax return information. Every data access must be scoped to the authenticated user. Cross-client data leakage = criminal liability.
Form 8867 Due Diligence: $600/return penalty for missing EITC/CTC/AOTC/HOH due diligence. The system must track and enforce due diligence documentation.
