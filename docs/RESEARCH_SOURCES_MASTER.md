# Petal research authority sources — master list

Generated from a 13-agent research sweep (63 sources). Each source is classified by the §6662 substantial-authority framework (Treas. Reg. 1.6662-4(d)(3)(iii)) and the 3-axis model (statute; courts by level+circuit; agency). "Wireable" = a free, documented, no-login endpoint we can integrate now.

Petal already ingests: federal statute (GovInfo USCODE + PLAW), Treasury regs (Federal Register), the IRS Internal Revenue Bulletin, and U.S. Tax Court (DAWSON).

## Build sequence

### Wave 0 — Shared credential + keyless API spine (Day 1, hours not days)

One free api.data.gov key unlocks every GovInfo collection plus Congress.gov and Regulations.gov; eCFR and Federal Register need no key at all. Provisioning this credential + the two keyless reg APIs is the foundation every later wave reuses. Zero auth friction, highest fan-out per unit of work. eCFR Versioner is the keystone: it makes a §1.199A-5-style reg citation fetch-VERIFIABLE and point-in-time grounded (the moment a correct cited reg answer stops being stamped 'not grounded').

Sources: api.data.gov shared key gateway (meta-credential); eCFR Versioner API — point-in-time CFR full text + structure (ALL titles incl. 26, 31, 12, 17, 48); eCFR Search + Admin APIs (full-text search + agency tree/corrections); Federal Register API — proposed & final rules and notices (all titles, IRS/Treasury rulemaking)

### Wave 1 — Highest value × clean free API, wireable this week

Directly attacks the two called-out priorities. (a) STATE CONFORMITY / the California §1202 gap: leginfo RTC is a deterministic, license-clean scrape (predictable lawCode=RTC&sectionNum= URLs, public domain) anchoring §17024.5/§23051.5 + decoupling; FTB Pub 1001 PDFs serve directly (the HTML page 403s) as the one-fetch nonconformity grounding; Tax Foundation supplies the 50-state fixed-date-vs-rolling routing signal so Petal applies the IRC as of the right date. (b) fetch-VERIFYING model-emitted citations: CourtListener v4 + its Citation-Lookup endpoint confirm a case cite resolves to a real opinion with precedential_status, so a correct cited answer stops being 'not grounded' and a hallucinated one is caught. Circuit tagging via CourtListener gives the Golsen/circuit-split axis. Circular 230 (Title 31), CRPT + JCT Blue Book (substantial-authority legislative history), and the Title 12/17/48 eCFR pulls are all near-free reuses of the Wave 0 spine. EDGAR is a clean no-login REST family for ASC 740 / book-tax context.

Sources: California Revenue & Taxation Code (RTC) — leginfo.legislature.ca.gov; California FTB — Conformity page + Publication 1001 (annual PDF); State IRC conformity surveys — Tax Foundation (free) / Bloomberg Tax / Tax Notes (paywall); CourtListener REST API v4 (Free Law Project) — federal + state case law, clusters, dockets, courts; CourtListener Citation-Lookup API v4 (cite verification / hallucination guard); Circular 230 — 31 CFR Part 10 (practitioner conduct standards); Congressional committee & conference reports (CRPT) — GovInfo + Congress.gov; JCT Blue Book (General Explanation, JCS series) + JCX technical explanations — GovInfo CPRT; SEC EDGAR — submissions, XBRL companyfacts/frames, Full-Text Search APIs; CFR Title 12 — Banks and Banking (OCC/Fed/FDIC/NCUA/CFPB); CFR Title 17 — Commodity & Securities Exchanges (SEC/CFTC); CFR Title 48 — Federal Acquisition Regulation (FAR) + Cost Accounting Standards (CAS)

### Wave 2 — Free, slightly heavier (official-source backfill, IRS guidance, bulk corpora)

Closes the federal authority spine with official-provenance text. GovInfo USCOURTS + CourtListener bulk + CAP together give the full non-Tax-Court federal case corpus (circuit/district/CFC/SCOTUS, historical to 1658) that DAWSON never reaches — bootstrap historically via free bulk/S3 to avoid API ceilings, then keep current via the Wave 1 API. irs-drop (rr-/rp-/n-/a-/td-) is the clean per-document, advance source for substantial-authority Rev. Ruls./Procs./Notices/TDs (closes the IRB latency + document-granularity gap). The irs-wd folder (one wholesale ingest = PLR+TAM+CCA+SCA+FSA, ~77k docs) is entirely missed today and must be tagged precedential=false. CDOC treaty text reuses the GovInfo key. IRM/Pubs/Instructions are scrapes Petal owns the freshness for. All free; effort is volume + scraping, not auth.

### Wave 3 — SALT depth, multistate models, international soft-law (free, fragmented multi-source)

Free but inherently fragmented or lower-leverage. SALT depth is a per-source scrape/seed problem: Socrata (structured rate facts), SST matrices and MTC/UDITPA models (apportionment/nexus backbone behind ~30 states), Open States (conformity-bill early-warning), Justia (50-state code mirror), LII (the WHERE-each-state-lives index to seed ingestion), and tribunal scrapes (NY DTA / CA OTA, flagged for nonprecedential handling). International soft-law (Pillar Two, US Model, treaty TEs/tables) and the secondary IRS guidance families (AOD/AM/CC-Notice, FS/FAQ with dated-snapshot capture for the §6662 reliance defense) round out coverage. Green Book, Regulations.gov, and the oversight/statistics bundle are explicitly non-authority context — ingest gated so the abstaining engine never grounds a position on them.

Sources: State open-data portals — Socrata SODA API (data.ny.gov etc.); Streamlined Sales Tax (SST) — Taxability Matrices, CRIC, Library of Definitions; Multistate Tax Commission (MTC) — model statutes & uniformity regs (UDITPA, apportionment, P.L. 86-272); Open States API v3 + bulk (Plural) — state legislation / conformity-bill tracking; Justia State Codes (50-state statute mirror); Cornell LII — U.S. Code / CFR / state index / Wex (deep-link + finding aid); State tax tribunals & state court tax decisions (NY DTA, CA OTA, state courts); OECD Pillar Two — GloBE Model Rules + Consolidated Commentary (2025) + Administrative Guidance; U.S. Model Income Tax Convention (2016) + Treasury Model TE; Treasury Technical Explanations (TEs) of U.S. income tax treaties; IRS Tax Treaty Tables (Table 1 withholding rates, Tables 2/3); Actions on Decisions (AOD) — IRS acquiescence/nonacquiescence; Associate Chief Counsel legal advice memoranda (AM) + Chief Counsel Notices + GCMs; IRS Fact Sheets / FAQs / Tax Tips (newsroom guidance); U.S. Bilateral Income Tax Treaties — Treasury treaties page + IRS 'A to Z' index (PDF corpus); Tax Information Exchange Agreements (TIEAs) + FATCA IGAs; U.S. International Social Security (Totalization) Agreements; Treasury Green Book; Regulations.gov API — rulemaking dockets + public comments; Oversight & statistics — TIGTA, GAO, IRS Data Book/SOI, CBO, Treasury OTA

### Wave 4 — The hard ones: paywalls, full 50-state codes/regs, foreign codes, accounting standards

Lowest value×ease: no clean free API, per-state/per-country adapters, login-walls, or commercial licensing. Full 50-state official codes + DOR Administrative Codes + local ordinances are bot-hostile per-jurisdiction scrapes (many on government-branded Westlaw/Lexis portals) — defer until Wave 1 CA-first conformity proves the pattern. PTET is high-churn multi-source. Foreign codes (IBFD paywall, no API) and the OECD full Commentary (iLibrary subscription) need licensing or abstain/escalate handling. FASB ASC prose is login-walled with no endpoint (use the free XBRL taxonomy for 'which concept' only); SSTS/PCAOB/AICPA are static/paywalled document fetches. The pre-2008 C.B. exists only as OCR-quality GOVPUB-T22 scans. PACER is paid (its needed opinions are already free in Waves 1-2). Build only as specific demand justifies the per-source cost.

Sources: State statutory codes — official 50-state legislature/code-reviser sites; State DOR administrative regulations (state Administrative Codes); Local tax ordinances (municipal/county) — Municode / eCode360 + DOR rate tables; State PTET (pass-through entity tax) statutes + DOR guidance; State PTET / conformity finding-aids — AICPA PTET tracker; Foreign statutory codes / corporate-entity statutes; Historical Cumulative Bulletin (C.B.) — permanent-citation backfill 1919–2008; US GAAP — FASB Accounting Standards Codification (ASC) + XBRL GAAP Taxonomy; OECD Model Tax Convention + Commentary (Condensed Version); AICPA Statements on Standards for Tax Services (SSTS) + Code of Professional Conduct; PCAOB Auditing Standards + AICPA Professional Standards (SAS/SSARS/SSAE); PACER / RECAP — federal dockets & filings; Justia — free case law host (deep-link/citation target)
